# Volleyball Manager

バレーボール大会における選手管理・交代管理を支援するツールです。

主な機能

- 選手登録
- コート配置管理
- 出場Pt管理
- サーブ順管理
- 女性人数チェック
- スコア管理

# コート配置

```text
      ネット

┌────┬────┬────┐
│ ④  │ ③  │ ②  │
│ LF │ CF │ RF │
├────┼────┼────┤
│ ⑤  │ ⑥  │ ①  │
│ LB │ CB │ RB │
└────┴────┴────┘
```

### ポジションの役割

#### ③ セッター

可能な限り2本目のボールを触り、前衛へつなぐポジションです。

競技経験者向け。

---

#### ②④ 前衛左右

アタック・ブロック担当。

セッターからのボールを相手コートへ返す役割です。

---

#### ⑥ 後衛中央

レシーブの中心となるポジションです。

相手サーブが集まりやすいため、レシーブが得意な方に向いています。

---

#### ①⑤ 後衛左右

レシーブとカバー担当。

こぼれ球をつなぎ、状況によっては積極的な返球やアタックも狙います。

# 操作方法

## 1. 選手登録

「選手登録」画面で

- 名前
- 性別
- ポジション

を入力し登録します。

登録した選手は試合画面のサーブ順、ベンチに自動追加されます。

---

## 2. コート配置

試合画面で、ベンチの選手カードをコート内の適当なポジションにドラッグ＆ドロップしてください。
今大会のレギュレーションにより、女性2名以上がコートにいる必要があります。条件を満たすと上部に☑が付きます。

---

## 3. 交代

ベンチの選手をコート上のポジションへドラッグすると、自動で交代します。


---

## 4. スコア入力

### 自チーム

```text
－ 12 ＋
```

### 相手チーム

```text
－ 10 ＋
```

得点が入るごとに＋ボタンを押してください。

自チーム・相手チームどちらの得点でも、その時点でコートに出ている選手の出場Ptが加算されます。

---

## 5. 得点リセット

```text
得点リセット
```

ボタンで、

- 自チーム得点
- 相手チーム得点

をリセットできます。

出場Ptは保持されます。

---

## 6. 出場Ptリセット

```text
出場Ptリセット
```

ボタンで、

全選手の出場Ptを0に戻します。

スコアは保持されます。

試合ごとに出場Ptをリセットしたい場合に使用してください。

---

## 7. サーブ順管理

登録順にサーブ順が作成されます。また、出場中の選手は名前の隣にチェックマークがつきます。

### 順番変更

↑ ↓ ボタンで調整可能。

### サーブ終了

「サーブ終了」を押すと、

先頭の選手が最後尾へ移動します。

---

### 色の意味

🟩 緑：現在サーバー

🟨 黄：次のサーバー

---

## 8. 女性人数チェック

コート上の女性人数を自動判定します。

- 2名以上：正常表示
- 不足：警告表示

# 大会当日のおすすめ運用

## 試合開始前

- 選手登録
- サーブ順調整
- 初期配置

## 試合中

- 得点入力
- サーブ順更新
- 選手交代

## 試合終了後

- 得点リセット
- 出場Ptリセット

## 次の試合へ

同じ選手情報・サーブ順を維持したまま運用できます。
